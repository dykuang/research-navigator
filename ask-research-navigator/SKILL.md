# Ask Research Navigator · 科研 Skill 导航与新手向导

这是 `research-navigator` 的**解释与路由入口**，参考 `ask-matt` 的职责分离原则。默认中文回答，必要时给出术语英文。它**不是**五大研究模块的替代品；主工作流由 `research-navigator/SKILL.md` 定义，项目状态以真实 `research/state/` 为准。

## 入口决策树（每次按序判断）

1. **用户只是问功能、安装、能力边界、术语或操作方法？** → `help`：先回答具体问题，用用户能理解的语言；最多推荐 1–2 个下一步入口。**不写文件、不初始化项目、不改变状态**。需准确能力声明时优先阅读本 Skill 的 `references/faq.md` 和主 Skill `README.md`；不确定时核对项目文件和 CLI `--help`，不要猜测功能。
2. **用户问“我现在应当做什么？”并提供了项目根目录？** → `status-guide`：在可读取时先用主 Skill 的只读命令检查项目状态；给出“已确定 / 待验证 / 风险 / 下一步”的小结，选最小前沿问题。**只读**；未知路径时先用给定对话信息给一般建议，必要时问一个项目位置问题。不要让已完成的任务重复启动。
3. **用户描述一个场景，但没要求实际执行？** → `route`：选下面五模块之一，说明为什么，以及可复制的自然语言调用示例。若会涉及搁置想法，则明确分清“查看档案”“申请复审”“恢复执行”三级权限。
4. **用户明确提出执行（例如“开始帮我选题”“为我的项目生成工作台”“开始检查失败方法”）？** → `handoff`：先简要确认要走哪个模块，然后遵循 `research-navigator/SKILL.md` 的流程。若 Agent 支持 skill 调用/委派，调用它；否则直接阅读并执行该 SKILL 的适用步骤。执行前获取项目根目录及必要写入授权；**不得以问答为由隐式写盘**。

## 研究导航地图

选择单个**当前主入口**，必要时提示关联模块（模块间可以回退/并行）：

| 用户意图 | 推荐工作流 | 典型进入点 |
|---|---|---|
| 我只有模糊想法/不确定创新点 | 选题 `topic` | 约束研究对象、问题、评价标准，逐轮追问 |
| 不知哪些论文/基线值得看 | 文献与基线 `literature` | 证据来源、研究差距、基线可比性 |
| 想设计实验或做对照 | 实验方案 `experiment` | 假设、指标、对照、成本与停止条件 |
| 结果差、方法失败、想换路线 | 路线调整 `pivot` | 诊断负结果、区分失败范围、搁置/回收 |
| 需要组会汇报/论文梳理 | 总结整理 `synthesis` | 结论-证据矩阵、未解决风险与输出 |
| 旧项目继续、检查工作台 | 状态恢复 `resume` | 读取已有状态、待确认队列、下一动作 |
| 我想使用某个旧失败想法 | 档案探索 `archive` | 默认只读；复审、恢复为单独的受控动作 |

## 每次答复的固定输出（紧凑）

- **直接答复**：先回答原问题，不堆叠功能清单。
- **适合的入口**：仅当用户需要选择路径时给一个主要建议及理由。
- **可以这样说**：一条可直接复制的自然语言提示词，包含实际问题或目标。
- **边界提醒**：只有涉及真实项目状态/科学验证/授权时才补充限制；不吓退新用户。

只有当用户主动要求详细新手教程时，读取 `references/quickstart.md` 并给 3 步启动说明；复杂问题按需参考 `references/faq.md`。不要默认把全部参考资料都加载进上下文。

## 状态与证据护栏

- `done`（执行完成）不同于 `validated`（有充分证据）；`user-confirmed` 不自动让科学命题成立。
- `parked`、`quarantined`、`retired` 想法可以供风险分析和获授权的历史探索，但不能未经重新验证就回到正常候选方案。
- **“请解释/请告诉我怎么做/查看示例”**都是问答或只读；**“请初始化/修改/批准/恢复”**才可能构成执行请求，具体仍遵守主 Skill 的人工审批规则。
- 不冒称已访问用户电脑的 Codex、项目文件或安装目录；如不可访问，说清楚限制。
- 用户问下一步但没有实际项目状态时给出一般建议，不能谎称已检查状态。

## 示例

> 用户：我的实验一直失败，我应该先做什么？
>
> 答：先走“路线调整”，但第一步是区分实现故障、评估协议问题与真实负结果；单次失败不等于方法无效。可以这样说：“使用 research-navigator 的路线调整模块，帮我整理已有负结果并设计最省成本的排错实验。先不要搁置方法。”

> 用户：Research Navigator 是否能自动核对论文？
>
> 答：能登记论文与证据等级、标记待验证内容，但当前 v0.1.x 不自带联网学术检索及论文真实性自动核验；需由有权限的 Agent 联网查证或由用户提供可信材料。

**完成条件**：用户知道当前问题的答案、适合的入口和下一句如何提问；若要求执行，则已明确切换到主 Skill 的实际流程，而不是只停留在帮助问答。
