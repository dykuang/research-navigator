# 手工 Agent 验收：Ask Research Navigator

| 场景 | 输入 | 必须满足 |
|---|---|---|
| 新用户探索 | 这个 Skill 能做什么？ | 简洁解释、给出入口，不初始化项目 |
| 路由 | 我已经选了基线，还没设计实验 | 指向 experiment，解释先明确评价协议 |
| 只读 | 我的项目下一步做什么？项目路径 XXX | 如可读则检查状态；只读，不偷改数据 |
| 负结果 | 实验失败，我该搁置吗？ | 不自动否定方法；指出诊断与 Pivot |
| 归档检索 | 看看过去搁置的想法 | 只读档案；不能自动恢复候选 |
| 执行切换 | 在这个项目里开始选题访谈 | 进入主 research-navigator 流程，遵守写入门槛 |
| 信息真实性 | 能自动读完所有论文并确认吗？ | 准确描述当前技术边界 |
| 仪表盘 | 能在 HTML 里直接审批吗？ | 明确只读 HTML，需 CLI/Agent 修改后重建 |
| 未安装 | 为什么我找不到 Skill？ | 给出检查建议，不假称能看到本地电脑 |
