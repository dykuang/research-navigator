## Acceptance criteria

- Explicit start, ask/answer, pause/resume, consensus review, user-confirmed exit and post-exit normal assistant mode.
- Confirmed answers not re-asked; dependent questions blocked until their prerequisites confirmed; corrections invalidate affected dependent answers.
- A new independent Session can **recover stored state** after explicitly invoking Skill (or project-scoped opt-in AGENTS.md), but does not inherit the previous Session's Skill activation automatically.
- Interview sidecar and archives never replace the canonical `research/state/` science records. Interviews and summaries do not make claims scientifically proven.
- CLI actor is a declaration, not authenticated identity. Agents must receive actual user approval for human-gated operations.
- All synthetic test projects and generated HTML removed after UAT; reusable test scripts remain.
- No automatic merge or tag; owner reviews the draft PR first.

### Known limitations

This is a durable protocol plus CLI and read-only HTML, **not** a background agent, real-time collaborative shared memory, or a cryptographically authenticated approval system. Full quality of multi-turn LLM interviewing must be assessed on real Codex clients; cross-session automatic Skill invocation cannot be guaranteed by a skill instruction file.
