## Release conditions

- Every Grilling question accepts Other text, even when available native options are unsuitable.
- Where Codex actually exposes `request_user_input`, only pass valid native payload and wait for the user; where unsupported, show an honest textual alternative. Preview JSON does not constitute invocation.
- Persist choice ID and user custom text without changing canonical scientific evidence state.
- Legacy v0.4.1 sidecar questions/answers remain loadable without forced migration.
- UI creates **only** copyable drafts; no misleading browser save or approval.
- No invented user confirmation, no auto exit from Grilling, no silent archive revival.
- Native Windows/Linux tests and Chromium pass; all generated synthetic projects are cleaned.
- Draft PR remains unmerged until explicitly approved; no tag/release is implied.
