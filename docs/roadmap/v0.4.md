## Purpose

Offer an evidence-aware decision frontier for researchers navigating uncertainty: identify current evidence gaps, explain candidate distinguishing tests, and help a mentor choose between continuing, narrowing or revisiting a parked route. Unlike a task recommender, this assistant explicitly separates **recorded facts**, **human decisions**, **inferred gaps**, and **unvalidated next-check ideas**. It never executes experiments, promotes a scientific claim, or revives a method on its own.

## Core architectural decisions

1. No change to canonical state schema **0.2.0**: v0.4 data is generated by deterministic read-only projections over the v0.3 stored graph.
2. The evidence gap `code` describes a missing check, not a scientifically measured risk. Most quality checks are *flagged*, not asserted as fact. Cross-source scope overlap is **not** calculated.
3. The “next check” recommendation lists a falsifiable observation, the intended uncertainty reduction, assumptions, and a `human_review_required` flag. `estimated_cost` defaults to `unknown`; `expected_information_value` remains `uncertain`. Neither is a numeric probability of success.
4. The archive watchlist is **read-only** and deliberately never auto-revives a method. Matching any new facts to recorded revival conditions requires human examination. Normal planning remains gated by `rn_core.query`.
5. Mentor briefs describe **scientific** Milestones and linked evidence, not GitHub issue milestones. Acceptance notes remain human-attributed audit records, not scientific validation.
6. The offline Research Canvas generates `research/canvas/decisions.html` as a snapshot. Its recommendations do not trigger the authenticated localhost proposal bridge; all semantic changes continue to require preview → pending proposal → interactive terminal approval.

## Usage

```bash
python scripts/v04_project.py PROJECT_ROOT gaps
python scripts/v04_project.py PROJECT_ROOT opportunities
python scripts/v04_project.py PROJECT_ROOT archive
python scripts/v04_project.py PROJECT_ROOT brief --format markdown --output advisor.md
python scripts/build_dashboard.py PROJECT_ROOT
# Open PROJECT_ROOT/research/canvas/decisions.html
```

See [reference](../../references/decision-v04.md) for exact semantics and use limitations. No external paid SDK, backend, or network connection is required for the decision page.
