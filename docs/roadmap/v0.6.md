GitHub milestone #5: https://github.com/dykuang/research-navigator/milestone/5

## Goal
Unify Grilling questions/answers, Claim–Evidence, ResearchBranch routes, ExperimentRun, scientific Milestones, outputs and SessionRef within one Blender-style typed research node editor. The UI is a projection; it does not create an alternative scientific truth database.

## Compatibility gate
The separate v0.5 Multi-Harness PR #66 is not merged. Before implementing #75, integrate/rebase its provider-scoped SessionRef and handoff contracts, without ingesting full chat transcripts.

## MVP researcher journey
Grilling Q-0001 with Other and supplement → research branch A/B → hypothesis → experiment/run → negative result and scoped contradictory evidence → scientific Milestone gate → evidence-backed claim/output; inspect SessionRef context. Editing any scientific edge must remain preview → protected pending proposal → explicit terminal approval. Archived branches stay isolated. Offline snapshots never write scientific state.
