# M5 · 总结整理与交付 (Synthesis & Delivery)

**Entry**: any time. It is a continuous module, not only after all experiments finish. **Exit**: coherent, caveated and traceable research output whose central statements link to real support/contradiction/unknowns, plus reproducible artifacts as applicable.

**Frontier interview**: intended reader (advisor, group, committee, journal), acceptable evidence threshold for each central claim, what remains unconfirmed, what the most informative negative result says, realistic contribution boundary, confidentiality/licensing and reproducibility expectations.

**Agent investigates**: cross-check Claim → Result → Experiment/Hypothesis via links; review negative/inconclusive/archived evidence with appropriate scope; identify unwarranted generalizations; verify code and artifacts that actually exist; distinguish narrative from empirical support. Report the unknown explicitly.

**Human decisions**: scientific interpretation, confidence of central contribution, whether a result is publishable and what is shared externally. Publishing requires explicit approval.

**Artifacts**: `research/05-synthesis/claim-evidence-matrix.md`, `contributions-and-limitations.md`, `reproducibility-checklist.md`, `project-summary.md`; optional adviser brief, paper outline and handoff. Checklist: dataset version/access, code commit, parameters, seed, environment, run logs, figure source, license and ethics.

**Rollback/links**: archived negative results remain part of analysis, but are never automatically reclassified as positive proof. New or conflicting literature changes the scope of a novelty claim; changed protocols mark derived claims `needs-review`.
