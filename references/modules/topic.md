# M1 · 选题 (Topic Selection)

**Entry**: student has an interest, problem observation, advisor theme, or open research goal. Can start even without a paper title. **Exit**: a falsifiable, resource-compatible working research question and low-cost next test; remaining uncertainties are explicitly tracked, not forcibly resolved.

**Frontier interview** (ask 2–5 independent questions, not all at once): what phenomenon should change for whom; what is the empirical/theoretical unit; how will success/failure be operationally measured; practical time, data, ethics, equipment, compute and supervisor constraints; what alternative interpretations threaten novelty; preferred outcome (paper, prototype, data, analysis). Offer two candidate directions where feasible, with viability and cost comparison; if only one, explain why.

**Agent investigates**: related terms/synonyms, known benchmark tasks if applicable, environment capabilities and available resources, falsifiable edge cases, key unknowns suitable for a cheap feasibility check. Consult literature module when novelty claims depend on prior work. Do not claim a gap solely from intuition.

**Human decisions**: research object and scope; risk appetite and resource budget; which candidate to test first; ethical approval constraints. Important unverified novelty stays `uncertain` or `hypothesis`.

**Artifacts**: `research/01-topic/topic-brief.md` (background, scope, contributions proposed, excluded scope); `research-questions.md` (IDs, hypotheses, metrics, falsification); `feasibility.md` (resources, barriers, MVE, stop conditions). Create only when content exists. Record key claims as items and link explicit prerequisites.

**Rollback/links**: if literature finds a comparable predecessor, revisit novelty rather than deleting the question. If experiments fail, revisit whether failure is data/implementation/problem setup. The summary module can record progress at any time.
